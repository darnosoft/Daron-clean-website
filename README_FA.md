# وب‌سایت گروه صنعتی دارنو کلین

وب‌سایت فارسی و راست‌چین، واکنش‌گرا، با سبک بصری کرم، طلایی و صورتی ملایم بر اساس تصاویر ارسالی.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای توسعه راحت‌تر می‌توانید پوشه را در Replit آپلود کنید.

## انتشار در Replit
1. وارد https://replit.com شوید و یک پروژه HTML/CSS/JS یا Static Site بسازید.
2. فایل‌های این پوشه و پوشه `assets` را آپلود کنید.
3. `index.html` را اجرا و پیش‌نمایش را بررسی کنید.
4. برای انتشار عمومی، از بخش Deploy/Publish و گزینه‌های موجود در حساب خود استفاده کنید؛ دسترسی و هزینه امکانات ممکن است تغییر کند.

## انتشار در Vercel
1. پوشه پروژه را در یک مخزن GitHub قرار دهید.
2. وارد https://vercel.com شوید و مخزن را Import کنید.
3. برای این سایت استاتیک معمولاً نیازی به Build Command نیست؛ خروجی پروژه همان ریشه پوشه است.
4. Deploy را بزنید.

## پیش از انتشار نهایی
- ایمیل رسمی، شماره تماس، آدرس کارخانه، شبکه‌های اجتماعی و اطلاعات مجوزها را اضافه کنید.
- فرم تماس در حال حاضر فقط آماده‌سازی پیام را نمایش می‌دهد. برای دریافت واقعی پیام‌ها باید ایمیل شرکت در `script.js` تنظیم شود یا یک سرویس فرم/بک‌اند اضافه کنید.
- عکس فعلی، تصویر مجموعه محصولات ارسالی است و برای نمایش جداگانه هر محصول موقتاً در چند کارت استفاده شده؛ برای نتیجه حرفه‌ای‌تر، عکس مجزای هر محصول را جایگزین کنید.
- متن‌های معرفی و ادعاهای کیفیت عمداً عمومی نوشته شده‌اند؛ مشخصات واقعی، استانداردها و گواهی‌ها را فقط پس از تأیید شرکت اضافه کنید.
